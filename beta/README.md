# ScopeGuard beta: 5 freelancers, 2 weeks

**Goal:** find out whether working freelancers can install ScopeGuard on their own, trust its verdicts on real client requests, and would pay to keep using it.

## What's in this kit

| File | For | Use it to |
|---|---|---|
| [OUTREACH.md](OUTREACH.md) | You | Find testers: where to post, and messages ready to adapt |
| [APPLICATION_FORM.md](APPLICATION_FORM.md) | You → applicants | Screening questions to paste into Google Forms or Tally |
| [TESTER_GUIDE.md](TESTER_GUIDE.md) | Testers | Install, first project, daily use, what to record |
| [request-log.csv](request-log.csv) | Testers | One row per client request: ScopeGuard's verdict vs. theirs |
| [INTERVIEW.md](INTERVIEW.md) | You | 20-minute exit interview, including willingness to pay |

## Who you're looking for

Five people, one from each field:

| Field | Why |
|---|---|
| Graphic / brand designer | Revision rounds, extra formats |
| Video editor | New aspect ratios, re-edits after approval |
| Web developer | Pages over count, bugs vs. new features |
| Social media manager | Retainers, extra platforms |
| Copywriter | Word counts, rewrites vs. edits |

**Must have:**
- an active client project with a written agreement (contract, proposal, quote or email)
- at least one client request expected in the next 2 weeks
- **Claude Code**, or willingness to install it. It needs a paid Claude plan, so screen for this first; it's the biggest barrier.

## Timeline

| When | You | Testers |
|---|---|---|
| Week 0 | Post, DM, screen applicants, pick 5 (plus 2 backups) | Apply |
| Day 1 | Send TESTER_GUIDE.md. **Don't help with installation;** just note where they get stuck | Install on their own, run the 5-minute demo |
| Day 1–2 | Check in once | Set up one real (anonymised) project |

| Day 7 | 5-minute check-in message | Send the log so far |
| Day 14–16 | 20-minute exit interview ([INTERVIEW.md](INTERVIEW.md)) | Interview, final log |
| Day 17+ | Turn every disagreement into an eval case; write up results | — |

## What testers get

Pick one and say it upfront:
- Free ScopeGuard Pro for 12 months when it launches.
- Or a small thank-you payment or gift card.

Don't promise features or dates.

## What counts as success (v3.0 bar)

- [ ] 4 of 5 install without your help
- [ ] 0 false extras that reached a client (included work wrongly called extra)
- [ ] No financial total disputed after checking it against the tester's own calculation
- [ ] At least 3 of 5 say they'd pay, and name a price
- [ ] At least 15 real requests logged across the group

## Ground rules

- **Privacy first:** testers anonymise client names, emails and personal details before sharing anything with you (see TESTER_GUIDE.md). Never ask for an unredacted contract.
- **Consent:** ask separately whether you may turn their anonymised examples into eval cases (the application form asks).
- **Not legal advice:** say it in every message. ScopeGuard drafts; the freelancer decides and sends.
- **Honesty:** record what went wrong as carefully as what went well. A failure found now is a fix before launch.
